AVITO WATCH — КРАТКО
====================

1. Вход (один раз): запусти "войти-в-avito.bat", войди в Avito в окне Chrome,
   вернись в консоль и нажми Enter.

2. Работа через окно: запусти "Avito Watch.bat" — откроется тёмное окно.
   Вставь ссылку на выдачу, нажми "▶ Запустить". Там же "■ Остановить",
   наработка, последние строки лога. Ссылок можно добавить сколько угодно,
   у каждой свой чекбокс вкл/выкл.

   Без окна: "запустить-скрыто.bat" — консоли нет, Chrome за краем экрана.
   Оповещения всё равно всплывают.

3. Старт: 1 минута тишины, потом запоминает текущую выдачу. Об уже висящих
   объявлениях не сообщает.

4. Дальше каждые ~45 с обновляет страницу. Следит только за верхними 7
   объявлениями. Новое объявление или смена цены — скриншот в shots, звук и
   окно справа внизу с нумерацией по ссылкам (1) ..., 2) ...). Каждое
   изменение пишется в изменения.txt: дата, цена, ссылка.
   Больше/меньше: python avito_watch.py --limit 3   (0 — вся страница)

5. Стоп: кнопка "■ Остановить" в окне, закрыть окно Chrome или Ctrl+C
   в консоли.

6. Живой лог: открой лог.html в браузере — там каждая проверка и каждое
   изменение, обновляется само каждые 3 секунды, в шапке видно, сколько
   всего наработано и сколько проверок сделано.
   Или запусти: python avito_watch.py --live (откроется сразу).

7. Общий лог: общий-лог.txt — всё за всё время, не стирается при
   перезапуске. Начало и конец каждого запуска отмечены, с наработкой.

Настройки:
  python avito_watch.py --interval 30     чаще проверять
  python avito_watch.py --interval 120    реже
  python avito_watch.py --start-delay 0   без стартовой минуты

Капча: реши её руками в окне Chrome, скрипт продолжит сам.

Сброс памяти: удали state.json.
