# История версий

Формат: [семантическое версионирование](https://semver.org/lang/ru/).
Тег в git совпадает с версией: `v1.0.0` ↔ `VERSION` ↔ `AppVersion` в `installer.iss`.

## 1.0.0 — 2026-11-13

Первый выпуск.

**Добавлено**
- Мониторинг выдачи Avito: сравнение объявлений по внутренним id
- Несколько ссылок на поиск, у каждой свой переключатель
- Настройка интервала проверки и числа первых объявлений
- Оповещение: звук, окно в правом нижнем углу, скриншот
- Отдельный профиль Chrome, окно за краем экрана, без иконки в панели задач
- Автоподъём браузера после закрытия
- Журналы: `общий-лог.txt`, `лог.html`, `изменения.txt`
- Окно с живым журналом и списком найденных объявлений
- Установщик Inno Setup: проверка Python и Chrome, установка зависимостей,
  ярлыки, вход в Avito после установки
- Интерфейс в стиле тёмного стекла со сглаженными углами
